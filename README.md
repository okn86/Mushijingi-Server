# 蟲神器サーバー

Minecraft 統合版サーバー「蟲神器サーバー」の案内サイトです。

**https://okn86.github.io/Mushijingi-Server/**

## 内容

- サーバー紹介ページ（ギャラリー付き）
- ワールドマップ（オーバーワールド / ネザー / エンド）
  - 地点のピンをタップすると名前・説明・座標が表示されます
  - 一覧から検索してその場所へ移動できます

## 生成について

マップは [uNmINeD](https://unmined.net/) で Bedrock 版のワールドデータから生成しています。
このリポジトリは生成物のみを置いています。
